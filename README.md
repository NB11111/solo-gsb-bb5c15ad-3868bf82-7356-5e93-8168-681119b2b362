# 走位轨迹碰撞排练台

为 2～8 名表演者设计走位的 Web 排练工具。为每人设置**身体半径**，在时间轴上编辑带时刻的
**二维走位点**（关键帧），系统在**分段直线运动**模型下用**解析方法连续计算任意两人的
碰撞时间区间——不使用任何离散帧抽样近似**。Canvas 画布可全程播放，危险区间内当事人
高亮，并给出**首次碰撞时刻**与**全局最小间距**。拖动任意走位点立即重算。内置一组
路径十字交叉 / 错峰 / 跟进贴近的样例。

## 一条命令启动（Docker Compose）

```bash
docker compose up -d --build
```

启动后访问： **http://localhost:3000**

依赖安装、构建全部在镜像内自动完成，宿主机无需 Node。

停止与清理：

```bash
docker compose down          # 停止
docker compose down --rmi local   # 停止并删除镜像
```

## 不用 Docker（本地 Node 直接运行）

要求 Node.js ≥ 18。

```bash
npm install        # 仅依赖 express
npm start
# 访问 http://localhost:3000
```

## 使用说明

- **选中表演者**：点击右侧列表；新增走位点都会加到当前选中者。
- **移动走位点**：在画布上直接拖动彩色圆点（位置变化），或在底部时间轴拖动对应泳道的圆点（改时刻）。**松手前实时重算**。
- **新增走位点**：选中某人后，在空白处单击（或双击）即可在**当前播放时刻**加入关键帧。
- **删除走位点**：右键画布圆点，或选中圆点后按 `Delete`（每人保留至少 1 个点）。
- **增减表演者**：右侧"＋增加 / ✕"，人数限制 2～8；半径范围 0～150 世界单位。
- **播放**：`▶ 播放`（或空格键），支持 0.25× / 1× / 2× / 4×；点击时间轴任意位置可跳转时刻。
- **红色高亮**：当前时刻处于碰撞区间的当事人，身体描边变红、显示红色半径盘，并用红色虚线连接冲突双方、标注实时间距。
- 右侧"逐对碰撞区间"列出每一对的精确碰撞区间（可有多段，已自动合并跨关键帧的相邻区间）、首碰时刻与最小间距。

## 算法：为什么不是帧抽样

每人在相邻关键帧之间是匀速直线运动，关键帧之外保持静止。对表演者 A、B，在两人活动段
的重叠时间窗 \[lo, hi\] 内，其相对位置是时间的一次函数：

\[
\mathbf r(t)=\mathbf p_A(t)-\mathbf p_B(t)=\mathbf u+\mathbf v\,t
\]

碰撞条件 \(\lVert\mathbf r(t)\rVert \le R_A+R_B\) 平方后是关于 \(t\) 的二次不等式：

\[
\lVert\mathbf v\rVert^2 t^2 + 2(\mathbf u\cdot\mathbf v)t + \lVert\mathbf u\rVert^2-(R_A+R_B)^2 \le 0
\]

用求根公式直接解出区间端点（判别式 < 0 表示全程不碰；\(\lVert\mathbf v\rVert=0\) 为
相对静止退化解，按恒定间距整段判定）。对两人分段活动区间做双指针扫描合并，得到
全部精确碰撞区间。最小间距取同一二次函数顶点（钳制在窗内）的全局最小值。
相切（距离恰好等于半径和）记为零长度碰撞区间。

该实现位于 `public/core.js`，浏览器与 Node 同一份代码，零第三方依赖。

## HTTP 接口

- `GET /api/sample` — 返回内置样例场景
- `POST /api/analyze` — 入参 `{ "duration": 12, "performers": [{ "name": "甲", "radius": 20, "keys": [{"t":0,"x":60,"y":300}, ...] }] }，返回每对碰撞区间、首次碰撞时刻与最小间距（前端实时编辑走本地同一引擎，此接口用于集成/校验）
- `GET /healthz` — 健康检查
