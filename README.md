# 走位轨迹碰撞排练台

为 2～8 名表演者设计走位的 Web 排练工具。为每人设置**身体半径**，在时间轴上编辑带时刻的
**二维走位点**（关键帧）；关键帧还可设置**可选安全半径**，用于表现开伞、展开道具等占用范围
随时间的变化。系统在**分段直线运动 + 分段线性半径**模型下用**解析方法连续计算任意两人的
碰撞时间区间——不使用任何离散帧抽样近似**。Canvas 画布可全程播放，半径盘随插值实时缩放，
危险区间内当事人高亮，并给出**首次碰撞时刻**与**全局最小间距**。拖动任意走位点或修改半径
立即重算。内置一组路径十字交叉 / 错峰 / 跟进贴近 + 跟进展伞的样例。

## 一条命令启动（Docker Compose）

```bash
docker compose up -d --build
```

启动后访问： **http://localhost:3000**

依赖安装、构建全部在镜像内自动完成，宿主机无需 Node。

停止与清理：

```bash
docker compose down          # 停止
docker compose down --rmi local   # 停止并删除镜像
```

## 不用 Docker（本地 Node 直接运行）

要求 Node.js ≥ 18。

```bash
npm install        # 仅依赖 express
npm start
# 访问 http://localhost:3000
```

## 使用说明

- **选中表演者**：点击右侧列表；新增走位点都会加到当前选中者。
- **移动走位点**：在画布上直接拖动彩色圆点（位置变化），或在底部时间轴拖动对应泳道的圆点（改时刻）。**松手前实时重算**。
- **新增走位点**：选中某人后，在空白处单击（或双击）即可在**当前播放时刻**加入关键帧。
- **删除走位点**：右键画布圆点，或选中圆点后按 `Delete`（每人保留至少 1 个点）。
- **编辑安全半径（开伞 / 展道具）**：点击任一关键帧圆点，右侧出现"选中走位点"面板，可编辑时刻、X/Y 与**安全半径**。
  - 半径**留空**表示继承该表演者的身体半径；填入数值（0～300 世界单位）即为该时刻的占用半径。
  - 相邻关键帧之间，半径与位置**同步线性插值**；首尾关键帧之外保持端点值。
  - 自定义半径的关键帧在画布上显示虚线范围环，播放时身体半径盘实时呈现当前范围；"↺ 继承半径"可一键还原。
- **增减表演者**：右侧"＋增加 / ✕"，人数限制 2～8；身体半径范围 0～150 世界单位。
- **播放**：`▶ 播放`（或空格键），支持 0.25× / 1× / 2× / 4×；点击时间轴任意位置可跳转时刻。
- **红色高亮**：当前时刻处于碰撞区间的当事人，身体描边变红、显示红色半径盘，并用红色虚线连接冲突双方、标注实时间距与当前半径和。
- 右侧"逐对碰撞区间"列出每一对的精确碰撞区间（可有多段，已自动合并跨关键帧的相邻区间）、首碰时刻与最小间距；半径随时间变化的双人对显示半径和区间（最小～最大）。

## 算法：为什么不是帧抽样

每人在相邻关键帧之间是匀速直线运动，**有效安全半径也在相邻关键帧之间线性变化**
（未设置半径的关键帧继承表演者身体半径，首尾之外保持端点值静止）。对表演者 A、B，在两人
活动段的重叠时间窗内，其相对位置与半径和都是时间的一次函数：

\[
\mathbf r(t)=\mathbf p_A(t)-\mathbf p_B(t)=\mathbf u+\mathbf v\,t,\qquad
R(t)=R_A(t)+R_B(t)=R_0+s\,t
\]

碰撞条件 \(\lVert\mathbf r(t)\rVert \le R(t)\) 平方后是关于 \(t\) 的**一般二次不等式**：

\[
(\lVert\mathbf v\rVert^2-s^2)\,t^2 + 2(\mathbf u\cdot\mathbf v-R_0s)\,t
+ \lVert\mathbf u\rVert^2-R_0^2 \le 0
\]

按二次项系数 \(\lVert\mathbf v\rVert^2-s^2\) 的符号分三种情形直接求根：

- **\(>0\)（开口向上）**：碰撞发生在两根之间——最常见的"穿过即离开"；
- **\(=0\)（一次/常数）**：覆盖相对静止、仅半径展开/收起等情形，单侧求根即得进入或离开时刻；
- **\(<0\)（开口向下）**：碰撞发生在两根之外——例如半径扩张速度始终快于相互远离速度时，
  一旦接触便持续到段末（同样包含两端都重叠的整段情形）。

判别式 < 0 表示二次式恒正或恒负（符号随开口方向定）；相切（距离恰好等于半径和）记为
零长度碰撞区间。对两人分段活动区间做双指针扫描合并，得到全部精确碰撞区间。
**几何最小间距**取相对位置抛物线 \(\lVert\mathbf r(t)\rVert^2\) 的顶点（钳制在窗内），
它只与运动有关，不受半径变化影响。

该实现位于 `public/core.js`，浏览器与 Node 同一份代码，零第三方依赖。引擎对关键帧半径的
回归测试含 400 个随机属性场景与密采样参考逐端点比对（另以 20000 组随机场景做过独立交叉
校验），保证解析结果不是帧采样近似。

## HTTP 接口

- `GET /api/sample` — 返回内置样例场景（其中丁的关键帧携带 `r` 字段作为可变半径示例）
- `POST /api/analyze` — 入参 `{ "duration": 12, "performers": [{ "name": "甲", "radius": 20, "keys": [{"t":0,"x":60,"y":300}, {"t":6,"x":500,"y":300,"r":55}] }] }`，返回每对碰撞区间、首次碰撞时刻与最小间距（前端实时编辑走本地同一引擎，此接口用于集成/校验）
  - 关键帧可含可选字段 **`r`**：非负数表示该时刻安全半径；缺省 / `null` / 空串时继承表演者 `radius`。
  - 旧场景数据（关键帧无 `r`）无需任何改动即可使用。
  - 每对结果新增 `variableRadius`（是否存在半径变化）与 `radiusSumMin` / `radiusSumMax`（该对在时间轴上半径和的最小/最大值；固定半径时与 `radiusSum` 一致）。
- `GET /healthz` — 健康检查
