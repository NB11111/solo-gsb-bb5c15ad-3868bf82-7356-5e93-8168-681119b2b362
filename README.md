# 走位轨迹碰撞排练台

为 2～8 名表演者设计走位的 Web 排练工具。为每人设置**身体半径**，在时间轴上编辑带时刻的
**二维走位点**（关键帧）；每个关键帧还可设置**可选安全半径**，用于表现开伞、展开道具等
占用范围变化（未设置时继承表演者当前半径，相邻关键帧间与位置同步线性插值）。系统在
**分段直线运动**模型下用**解析方法连续计算任意两人的碰撞时间区间——不使用任何离散帧
抽样近似**（半径和随时间变化时退化为一般二次不等式，同样精确求解）。Canvas 画布可全程
播放，危险区间内当事人高亮，并给出**首次碰撞时刻**与**全局最小间距**。拖动任意走位点或
修改半径立即重算。内置一组路径十字交叉 / 错峰 / 跟进贴近 / 到位展开道具的样例。

## 一条命令启动（Docker Compose）

```bash
docker compose up -d --build
```

启动后访问： **http://localhost:3000**

依赖安装、构建全部在镜像内自动完成，宿主机无需 Node。

停止与清理：

```bash
docker compose down          # 停止
docker compose down --rmi local   # 停止并删除镜像
```

## 不用 Docker（本地 Node 直接运行）

要求 Node.js ≥ 18。

```bash
npm install        # 仅依赖 express
npm start
# 访问 http://localhost:3000
```

## 使用说明

- **选中表演者**：点击右侧列表；新增走位点都会加到当前选中者。
- **移动走位点**：在画布上直接拖动彩色圆点（位置变化），或在底部时间轴拖动对应泳道的圆点（改时刻）。**松手前实时重算**。
- **新增走位点**：选中某人后，在空白处单击（或双击）即可在**当前播放时刻**加入关键帧。
- **删除走位点**：右键画布圆点，或选中圆点后按 `Delete`（每人保留至少 1 个点）。
- **关键帧安全半径**：选中任意圆点后，画布下方出现编辑条，可填写该帧安全半径（0～150 世界单位，留空继承表演者当前半径）。半径与位置在相邻关键帧间**同步线性插值**，首尾之外保持端点值；画布上选中者各帧会画出占用范围盘（实线＝自定义，虚线＝继承），播放时身体盘实时张开/收拢，时间轴上自定义半径的时刻柄有白圈标记。修改/拖动后立即刷新碰撞区间。
- **增减表演者**：右侧"＋增加 / ✕"，人数限制 2～8；半径范围 0～150 世界单位。
- **播放**：`▶ 播放`（或空格键），支持 0.25× / 1× / 2× / 4×；点击时间轴任意位置可跳转时刻。
- **红色高亮**：当前时刻处于碰撞区间的当事人，身体描边变红、显示红色半径盘，并用红色虚线连接冲突双方、标注实时间距与当前半径和。
- 右侧"逐对碰撞区间"列出每一对的精确碰撞区间（可有多段，已自动合并跨关键帧的相邻区间）、首碰时刻、最小间距与该对**半径和的变化范围**。

## 算法：为什么不是帧抽样

每人在相邻关键帧之间是匀速直线运动，**安全半径也在相邻关键帧之间线性变化**；
关键帧之外位置静止、半径保持端点值。对表演者 A、B，在两人活动段
的重叠时间窗 \[lo, hi\] 内，其相对位置与半径和都是时间的一次函数：

\[
\mathbf r(t)=\mathbf p_A(t)-\mathbf p_B(t)=\mathbf u+\mathbf v\,t,\qquad
R(t)=R_A(t)+R_B(t)=c+d\,t
\]

碰撞条件 \(\lVert\mathbf r(t)\rVert \le R(t)\)（两侧均非负，可直接平方）是关于
\(t\) 的一般二次不等式：

\[
\bigl(\lVert\mathbf v\rVert^2-d^2\bigr) t^2 +
2\bigl(\mathbf u\!\cdot\!\mathbf v-cd\bigr) t +
\lVert\mathbf u\rVert^2-c^2 \le 0
\]

用求根公式直接解出区间端点并钳制到重叠窗：首项系数可正（常规，碰撞段在两根之间）、
可负（半径张开速度大于接近速度，碰撞解集向两端开口，钳制后最多两段）、可为零
（线性/恒定退化）。判别式 < 0 时按开口方向判为整段碰撞或全程不碰；相对静止
（\(\lVert\mathbf v\rVert=0\)）情形由同一求解器覆盖——只靠半径张开也能精确解出
进入/脱离时刻。对两人分段活动区间做双指针扫描合并，得到全部精确碰撞区间。
**最小（几何）间距**取相对距离二次函数顶点（钳制在窗内）的全局最小值，与半径
变化无关。相切（距离恰好等于半径和）记为零长度碰撞区间。

该实现位于 `public/core.js`，浏览器与 Node 同一份代码，零第三方依赖。

## HTTP 接口

- `GET /api/sample` — 返回内置样例场景（含关键帧半径 `r`，如丙 t=8 帧 `r: 60` 表现展开道具）
- `POST /api/analyze` — 入参
  `{ "duration": 12, "performers": [{ "name": "甲", "radius": 20, "keys": [{"t":0,"x":60,"y":300}, {"t":8,"x":500,"y":300,"r":60}] }] }`。
  关键帧可选字段 `r` 为该帧安全半径（非负数；缺省或 `null` 即继承表演者 `radius`）。返回每对碰撞区间
  （含 `radiusSumMin` / `radiusSumMax` 半径和变化范围）、首次碰撞时刻与最小间距；响应额外携带
  `scene`，其中缺省半径已解析为具体数值，可直接回传。旧的无 `r` 场景数据完全兼容（前端实时编辑
  走本地同一引擎，此接口用于集成/校验）
- `GET /healthz` — 健康检查
